# WePic小工具

一个单页图片小工具：拼图 + 分图，全部在浏览器里处理，不上传图片。

原名拼图小工具（pintu-tool），现已改名 WePic。

## 功能

### 拼图

- 添加多张图片，点缩略图切换
- 9 种版式，点示例小图切换
- 间距、尺寸基准可调；拖动图片换位
- 导出 PNG / JPG / WebP，画质可调
- 导出动图 GIF：每张图一帧，按顺序循环播放，每帧停留 0.1–10 秒（默认 0.5 秒）

### 分图

- 把一张图切成多块，9 种切分方式：2×1、1×2、3×1、1×3、2×2、3×2、2×3、3×3、4×4
- 预览图上叠加切分线和编号，点缩略图选切哪张（默认第一张）
- 分割线可以拖：按住线中间的圆手柄拖动改比例，拖动时显示两边百分比；右上角「恢复均分」一键回到均分
- 按原图尺寸切，不缩放；按顺序编号逐个下载（PNG / JPG / WebP，沿用导出画质）

## 部署

```yaml
services:
  wepic:
    image: weleone/wepic:latest
    container_name: wepic
    restart: unless-stopped
    ports:
      - "8505:80"
```

```bash
docker compose up -d
```

打开 `http://服务器IP:8505` 即可使用。

## 用法

1. 点「添加图片」或把图片拖进页面
2. 顶部切换「拼图」或「分图」
3. 拼图：选版式、调间距，导出；分图：选切分方式、拖分割线调比例，导出
